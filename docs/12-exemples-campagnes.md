# Exemples de campagnes par secteur

Les 5 exemples ci-dessous sont préchargés par `supabase/seed-demo.sql` (clients, contacts et messages inclus).

## 1. Restaurant — Chez Demba (Angers)
Campagne : Match Côte d'Ivoire vs Sénégal · samedi 22h · Offre : Garba Thon 10 € · Cible : sport, VIP, habitués · Envoi : mercredi 18h · Rappel : 12h avant (samedi 10h).
Objectif : tables réservées. KPI : réservations, taux de réponse.

## 2. Salon de coiffure — Salon Belle Époque (Angers)
Campagne : Offre week-end coiffure · vendredi 10h · Offre : -20 % sur les prestations · Cible : clientes habituées, VIP · Rappel : 24h avant.
Objectif : remplir les créneaux du week-end. KPI : rendez-vous pris.

## 3. Boutique — Wax & Style (Nantes)
Campagne : Nouvel arrivage collection wax · samedi 11h · Avant-première VIP · Cible : VIP uniquement · Rappel : 12h avant.
Objectif : trafic en boutique le samedi matin. KPI : réponses INFO, visites déclarées.

## 4. Association — Teranga 49 (Angers)
Campagne : Réunion communautaire + repas partagé · dimanche 15h · Cible : membres, familles · Rappel : 24h avant.
Objectif : participation. KPI : « OUI » reçus (liste de présence auto).

## 5. Organisateur d'événements — Kaay Fecc Events (Paris)
Campagne : Soirée Afro · samedi 23h · Entrée sur réservation · Cible : participants précédents, VIP, étudiants · Rappel : 12h avant.
Objectif : pré-ventes. KPI : RÉSERVE reçus, taux de réservation.

## Recette d'une bonne campagne (à donner aux clients)

Un seul sujet par message · envoyée 2-3 jours avant l'événement · rappel 12-24h avant · une offre concrète chiffrée · un appel à l'action en un mot (OUI / RÉSERVE / INFO) · jamais plus de 4-6 campagnes par mois vers le même contact.
